## 🚀 3 Ways to Run / Download on Your Phone

### Option 1: Local Wi-Fi (No Internet Required) 📶
Play directly on your phone connected to the same Wi-Fi as your PC:

1. Double-click or run `python server.py` on your computer inside this directory.
2. It will display a link like:  
   `http://192.168.x.x:8000`
3. Open **Chrome** or **Safari** on your phone and type that URL.
4. *(Optional)* Tap **"Add to Home Screen"** in your phone's browser to install it as an app!

---

### Option 2: Host on GitHub Pages (Free Instant Link for Anyone) 🌐
Share a permanent link with friends so anyone can play from anywhere in the world:

1. Push this `mobile-quiz-app` folder (or repository) to GitHub.
2. Go to your repo **Settings** > **Pages**.
3. Select `main` branch and click **Save**.
4. GitHub will give you a free URL like:  
   `https://your-username.github.io/mobile-quiz-app/`
5. Open this link on any phone or share via WhatsApp!

---

### Option 3: Run via Termux (Android Terminal) 🤖
For Android users who want to run the terminal version directly on their phone:

```bash
# Inside Termux app on Android:
pkg update && pkg install python git -y
git clone https://github.com/Aneesh-labs/Class-9-and-10-MCQ-practice-quiz.git
cd Class-9-and-10-MCQ-practice-quiz/study-quiz-app
python app.py
```
